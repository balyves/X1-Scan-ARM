# {icon:rule} Règle de redressement

La Règle redresse une image penchée.

- Touche : R. L’outil ouvre Préparer › [Cadrage](prepare.md#framing).
- Tracez une ligne le long de ce qui doit être horizontal ou vertical.
- L’image tourne pour que la ligne devienne droite. L’[angle](prepare.md#angle) affiche la correction.
- Retour garde la correction. Échap l’annule.
- La ligne reste affichée jusqu’au changement d’outil. Si vous maintenez Espace pour déplacer l’image, la ligne reste. Pendant le tracé, Espace n’agit qu’une fois le bouton de la souris relâché.
- Elle disparaît aussi quand l’angle ou l’orientation change (Échap, [Réinitialiser le cadrage](prepare.md#reset), le champ Angle), et quand un nouvel aperçu démarre.
