# {icon:crop} Recadrage

Le Recadrage trace et ajuste le cadre de l’image.

- Touche : C. L’outil ouvre Préparer › [Cadrage](prepare.md#framing).
- Tracez un cadre sur l’image. Faites glisser ses coins pour le redimensionner, son centre pour le déplacer.
- Les [proportions](prepare.md#proportions) et le verrou s’appliquent pendant le tracé.
- X inverse largeur et hauteur.
- ← et → tournent l’image finement. Avec Maj, par pas de 5°.
- Retour (« Terminé ») garde les changements. Échap les annule.
- Le cadre change l’affichage, l’histogramme et l’export. Il ne change pas la zone numérisée.
