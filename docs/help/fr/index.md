# Aide de X1 Scan

X1 Scan pilote un scanner Hasselblad Flextight X1 depuis un Mac récent.
Cette aide décrit l’application telle qu’elle est aujourd’hui.

> Sur le X1 réel, X1 Scan lit pour l’instant l’identité et l’état du scanner. L’aperçu et la numérisation sur le X1 réel sont en cours de validation. Pour essayer toutes les fonctions sans scanner, utilisez le [mode découverte](discovery.md).
