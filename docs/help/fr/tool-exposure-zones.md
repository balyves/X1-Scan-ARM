# {icon:exposure-zones} Zones d’exposition

Les zones d’exposition montrent sur l’aperçu les pixels à surveiller.

- Bouton {icon:exposure-zones} de la colonne d’outils : afficher ou masquer les zones.
- En rouge : les pixels écrêtés, trop clairs pour le capteur.
- En violet : les pixels proches du bruit, presque noirs pour le capteur.
- Les zones viennent du dernier aperçu complet. Voir [Exposition](information.md#exposure).
- Elles ne sont jamais exportées.
