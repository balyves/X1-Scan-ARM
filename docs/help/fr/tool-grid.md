# {icon:grid} Grille

La grille aide à juger l’horizon et la composition. Elle n’est jamais numérisée ni exportée.

- Bouton {icon:grid} de la colonne d’outils : clic pour afficher ou masquer (⌘').
- Clic droit : type, couleur et opacité.
- Types : Tiers, Grille fine ou Croix centrale.
- Le menu Image › Carrés de la grille fine règle le nombre de carrés.
- La grille du cadre se règle à part, dans [Cadrage](prepare.md#crop-grid).
