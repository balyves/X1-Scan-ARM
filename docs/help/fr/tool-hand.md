# {icon:hand} Main

La Main déplace l’image dans la fenêtre.

- Touche : H.
- Faites glisser l’image pour la déplacer.
- Maintenez Espace pour prendre la Main un instant, depuis n’importe quel outil. Le pointeur doit être sur l’image ; le focus clavier peut être n’importe où, sauf dans un champ de saisie.
- Le pavé tactile fait aussi défiler et zoomer (pincement).
