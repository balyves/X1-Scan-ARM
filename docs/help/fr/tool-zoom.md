# Loupe

La Loupe agrandit ou réduit l’image.

- Touche : Z.
- Clic : agrandir. ⌥-clic : réduire.
- Le menu Présentation propose Ajuster à la fenêtre (⌘0), Remplir la fenêtre (⌥⌘0), Taille réelle (⌘1), Zoom avant (⌘+) et Zoom arrière (⌘-).
- La barre du bas montre le zoom. Vous pouvez y taper une valeur.
- Le zoom à l’ouverture d’une image se règle dans Réglages › Affichage.
