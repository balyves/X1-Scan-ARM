# Mode découverte

Le mode découverte permet d’essayer X1 Scan sans scanner.

## Entrer dans le mode {#enter}

- Choisissez Fichier › Essayer sans scanner.
- Au lancement, si la source est le X1 réel et qu’aucun X1 n’est trouvé, le message « Aucun X1 trouvé » propose aussi « Essayer sans scanner ».
- État du X1 : **indifférent**. Le mode découverte n’utilise jamais le scanner, même s’il est branché et allumé.

## Ce qui marche {#features}

- Un bandeau en haut de l’image rappelle « Mode découverte — aucun scanner branché ».
- L’[aperçu](first-scan.md#preview), le [cadrage](prepare.md#framing), les outils et la [numérisation](scan.md#scan-button) marchent comme avec un scanner.
- L’image vient d’un X1 simulé : une mire de test. L’aperçu a aussi une plage trop claire et une plage trop sombre, pour essayer les [zones d’exposition](tool-exposure-zones.md).

## Fichiers d’exemple {#files}

- Un fichier exporté ou numérisé en mode découverte porte le suffixe « _exemple » dans son nom.
- Sa description TIFF et sa recette le marquent comme exemple. Ce n’est pas une numérisation.

## Quitter le mode {#leave}

- Cliquez sur « Quitter le mode découverte » dans le bandeau, ou choisissez Fichier › Quitter le mode découverte.
- X1 Scan revient à la source d’avant. Si c’est le X1 réel, il le cherche à nouveau.
- S’il ne le trouve pas, le message « Aucun X1 trouvé » réapparaît, avec « Essayer sans scanner ».
- Pendant le mode découverte, la source ne se change pas dans Réglages › Scanner.
