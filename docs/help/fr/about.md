# À propos et licences

X1 Scan est un logiciel libre pour piloter le Hasselblad Flextight X1 depuis un Mac récent.

## Licences {#licences}

- Le code est sous licence MIT.
- L’icône de l’application n’est pas sous licence MIT. Elle appartient au titulaire de ses droits d’auteur. Voir le fichier LICENSE-ICON.
- Les deux textes sont dans le menu X1 Scan › À propos de X1 Scan.

## Ce que l’application ne contient pas {#contents}

- Aucun logiciel, firmware ni profil de Hasselblad.
- Le protocole du scanner a été décrit à partir de l’observation de FlexColor.

## Marques {#trademarks}

- Hasselblad, Flextight et FlexColor sont des marques de leurs propriétaires.
- X1 Scan n’est ni affilié à Hasselblad ni approuvé par Hasselblad.
