# Dépannage

Cette page explique les messages d’erreur de X1 Scan et ce qu’il faut faire.

Un garde-fou peut arrêter le scanner. C’est voulu : il protège l’appareil dès qu’une réponse diffère de ce qui est connu. Le message dit quoi faire.

Pour le X1 réel, le journal, dans le dossier X1-captures de votre dossier personnel, garde tout le détail technique.
