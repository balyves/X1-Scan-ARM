# {icon:grid} Grid

The grid helps to judge the horizon and the composition. It is never scanned or exported.

- Button {icon:grid} of the tool column: click to show or hide (⌘').
- Right click: kind, colour and opacity.
- Kinds: Thirds, Fine Grid or Centre Cross.
- Image › Fine Grid Squares sets the number of squares.
- The frame’s grid is set separately, in [Framing](prepare.md#crop-grid).
