# {icon:rule} Straightening Rule

The Rule straightens a tilted image.

- Key: R. The tool opens Prepare › [Framing](prepare.md#framing).
- Draw a line along what should be horizontal or vertical.
- The image turns so that the line becomes straight. The [angle](prepare.md#angle) shows the correction.
- Return keeps the correction. Esc cancels it.
- The line stays on screen until you change tool. If you hold Space to move the image, the line stays. Pressed while you draw the line, Space acts only after you release the mouse button.
- It also goes when the angle or the orientation changes (Esc, [Reset Framing](prepare.md#reset), the Angle field), and when a new preview starts.
