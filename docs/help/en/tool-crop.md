# Crop

The Crop tool draws and adjusts the frame of the image.

- Key: C. The tool opens Prepare › [Framing](prepare.md#framing).
- Draw a frame on the image. Drag its corners to resize it, its centre to move it.
- The [proportions](prepare.md#proportions) and the lock apply while you draw.
- X swaps width and height.
- ← and → turn the image finely. With Shift, by steps of 5°.
- Return (“Done”) keeps the changes. Esc cancels them.
- The frame changes the display, the histogram and the export. It does not change the area scanned.
