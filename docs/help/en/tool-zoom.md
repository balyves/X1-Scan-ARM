# Zoom

The Zoom tool enlarges or reduces the image.

- Key: Z.
- Click: zoom in. ⌥-click: zoom out.
- The View menu has Zoom to Fit (⌘0), Fill Window (⌥⌘0), Actual Size (⌘1), Zoom In (⌘+) and Zoom Out (⌘-).
- The bottom bar shows the zoom. You can type a value there.
- The zoom when an image opens is set in Settings › Display.
